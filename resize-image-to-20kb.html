How to Prepare Your Signature for 20 KB Portals

  • Use Crisp Black or Dark Blue Ink: A dark ballpoint or gel pen on clean, bright white unlined paper ensures the best contrast.
  • Good Lighting, No Shadows: Take the photo from directly above in natural daylight to prevent gloomy shadows that inflate JPEG file size.
  • Crop Away Blank Margins: The tighter you crop around the signature, the higher the resolution and clarity you can retain within 20 KB.

How many pixels can 20 KB afford?

A 20 KB file is 20,480 bytes, or 163,840 bits. How far that goes depends entirely on the pixel count, which is why the same limit can feel easy for one form and impossible for another.

Rule of thumb for photographs: 2.5 or more bits per pixel is comfortable, 1.5 to 2.5 is workable, below 1.5 looks soft or blocky.

The 350 x 450 portrait at 20 KB is the tight case. It has 157,500 pixels, so each pixel gets about one bit. Expect visible softness and blocky skin tones. If the form really requires both 350 x 450 and 20 KB, start from a sharp, evenly lit photo and a tight crop, and accept that the result will look plain.

Smaller pixel sizes change the picture completely. At 200 x 230 the same 20 KB gives more than three and a half bits per pixel, which is comfortable. Many forms that cap the file at 20 KB also allow or require a small pixel size, so always read the dimension line before reaching for the quality slider.

Signatures have room to spare. Even at 400 x 200 a clean black-on-white signature fits under 20 KB at good quality, so the thing to check is that the file is not smaller than any minimum the form sets.

  • Choose the dimensions first, then the size limit. Reversing the order leads to blurry compromises.
  • Crop out everything except the face or the signature: borders cost bytes.
  • Look at the finished file at 100 percent zoom, not on the preview thumbnail.

Frequently Asked Questions: 20 KB Signature Sizing

Common questions regarding the 20 KB limit.

What happens if my file is 20.2 KB?

Government exam portals measure file size strictly in bytes. 20 KB equals 20,480 bytes. If your file is 20.2 KB (20,684 bytes), the portal validator rejects the file. ApplyReady tests byte size iteratively to guarantee the output is strictly below 20,480 bytes.

Can I resize photos as well as signatures to 20 KB?

Yes. Any image, including ID photos and stamps, can be cropped and compressed to under 20 KB using this page.
