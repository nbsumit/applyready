Troubleshooting

Photo Upload Errors: What Each Message Means and How to Fix It

Match the message on your screen to the check that failed, then change the file. Retrying the same file rarely works.

ApplyReady guide | Published 11 October 2026 | Last updated 18 November 2026

Read the message, then change the file

Upload checks on job portals, university application forms and employer career sites look at a small number of things: the file type, the size in KB, sometimes the pixel size and the file name, and later, a recruiter or an HR team looks at the picture itself. The message you see tells you which check failed. This page groups the common messages by that check and gives the usual cause and the fix for each.

Two habits prevent most repeat failures. Start from the original camera photo or scan, not a copy that has already been shrunk, screenshotted or forwarded through a chat app. And when the same message appears twice, change the file instead of retrying it: an upload field applies the same check every time, so an unchanged file gets the same answer.

Size errors

"File size exceeds the maximum limit"

Cause: the file has more bytes than the field allows. Fix: resize to the pixel size the form asks for first, then compress. Shrinking the pixels costs far less quality than squeezing a large image: in our measurements a 350 × 450 px test portrait fitted under 20 KB at quality 0.92, while the same photo at 1000 × 1333 px needed quality 0.40 (20 KB page). Portals rarely say whether they count a kilobyte as 1,000 or 1,024 bytes, so ApplyReady keeps a maximum at 1,000 bytes per KB or less (50 KB is at most 50,000 bytes), which fits either way.

"File size is below the minimum"

Cause: many limits are ranges, for example a photo field that accepts 20 to 50 KB, or a signature field that accepts 10 to 20 KB. A small, clean image can come out under the minimum: our 140 × 60 px test signature was 3.2 KB. Fix: keep the stated pixel size and enter the minimum in the resizer's Minimum (KB) field. The tool pads the JPEG with comment data until it reaches the minimum, without changing the picture. Do not enlarge the image to gain bytes when the form fixes its pixel size.

Format and file errors

"Invalid file format" or "Only JPG/JPEG allowed"

Cause: the file is PNG, WebP or HEIC, or it was renamed rather than converted. Changing photo.png to photo.jpg changes only the name: a JPEG file starts with the bytes FF D8 FF and a PNG file with 89 50 4E 47, and a checker that reads the first bytes sees the difference. Fix: export a real JPEG. In the resizer, set the format to JPEG; JPEG is also the format that shrinks when quality is lowered, while PNG is lossless (MDN image format guide). The image formats guide explains when each format is the right choice, and the file checker shows the real type of any file next to its name.

"Unable to read file" or "File is corrupt"

Cause: an interrupted download, a file renamed from another format, or an unusual colour profile. Fix: open the original in the resizer and download a fresh JPEG; the browser re-encodes it from the pixels.

"File name is not valid"

Cause: some portals check the name. Some expect a fixed name such as photo or signature; others reject spaces, brackets or symbols, or very long names. Fix: rename the downloaded file exactly as the instructions say, using letters, numbers, hyphens and underscores only. If the form gives no rule, a short name such as firstname-lastname-photo.jpg is safe.

The photo appears sideways after upload

Cause: phones often store the picture unrotated and add an orientation tag; a server that ignores the tag shows it sideways. Fix: re-save the photo through the resizer. The browser applies the orientation when it draws the image, so the downloaded file is stored upright and needs no tag.

Size of the face or signature

"Image dimensions are not as per specification"

Cause: the width or height is outside the stated range, for example a portal that asks for a photo of exactly 350 × 450 px, or a signature between 300 and 500 px wide. Fix: enter the exact size in the resizer. If the form gives centimetres, switch the unit to cm and enter the DPI it states; pixels, cm, DPI and KB explains the conversion.

The face is too small, or the signature looks tiny

Cause: too much background around the subject. Forms that set a rule usually ask for the face to fill most of the photo and the signature to fill most of its box, because a small subject becomes unreadable once the image is shrunk to a few hundred pixels. Fix: crop tighter before resizing. The crop frame keeps the output shape, so you only choose how much of the photo goes inside it. For signatures, the signature cleaner trims empty paper around the ink before you resize.

"Photo is stretched"

Cause: the width and height were changed separately in another program. Fix: crop to the target shape first and let the tool resize; it never stretches the image to fit.

Accepted by the upload, questioned later

Some problems pass the automatic check and are noticed only when a person opens the application. These faults are easy to recognise and easy to fix before you apply:

  • Busy or dark background: a plain, light background reads as a deliberate photo; a bedroom wall or a crowd does not.
  • Blur and poor light: a photo that is soft or underexposed looks careless, even when it fits the size limit.
  • Caps, sunglasses and heavy filters: anything that hides or alters the face makes the photo less useful for identification.
  • A photo of a photo: re-photographing a printed picture adds glare and loses detail.
  • Signatures in capital letters or with smudged ink: a signature should look like the one you write on paper, in dark ink on clean white.

Blur and dark photos are fixed at the camera, not in software: retake the photo by a window with the back camera, as described in taking a passport photo at home. A grey or yellow signature background is fixed with the signature cleaner before resizing; signature images for online forms covers the whole process. Photos forwarded through chat apps are usually recompressed on the way, so transfer the original file instead.

When the upload itself fails

If the progress indicator spins or the page reloads without a message, the file is often not the cause. Check that you are still logged in, try another browser, allow the portal's pop-ups, and rename the file to plain letters and numbers. A smaller file also finishes sooner on a weak connection. If one document is a PDF that is too large, see compressing a PDF for upload portals.

Why does a file pass on one portal and fail on another?

Each portal sets its own rules. A 60 KB photo is fine for a form that accepts up to 200 KB but too large for one that accepts 20 to 50 KB. Keep your original photo and make a fresh copy for each form from that original, using the limits printed on that form. The document checklist lists what to prepare before you start.
