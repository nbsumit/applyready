How to Use ApplyReady

Comprehensive guide to resizing images under strict file-size limits and creating ATS-friendly resumes.

1. Resizing & Compressing Images

ApplyReady’s Image Resizer allows you to set exact output pixel dimensions (e.g. 350 × 450 px) and a strict maximum file size (e.g. 50 KB). Follow these steps:

  1. Choose an image: Drop a file into the image workspace or select Choose image. You can also try the sample document. Supported files are JPG, PNG, WebP, GIF, BMP and AVIF, up to 50 MB and 64 megapixels. Animated files produce a still image.
  2. Configure Output Format: Choose JPEG for photos, PNG for graphics needing lossless quality, or WebP for modern web delivery. If converting a transparent image to JPEG, pick a background fill color (White or Black).
  3. Set dimensions and a file limit: Choose a Quick start preset or enter your own width, height and maximum KB. Preset values stay editable. Check the requirements on the form you are applying to; a photo preset does not guarantee acceptance by a particular authority. On a phone, settings appear below the image workspace.
  4. Compress the whole image: Select Use original size to reset rotation, remove the optional text strip and include the entire source at its original dimensions. Then set the file limit. Output is limited to 20–8,000 pixels on each side and 32 megapixels; larger originals need smaller output dimensions.
  5. Adjust Your Crop: Use the interactive crop handles, rotation controls (±90°), and zoom buttons to frame your document perfectly.
  6. Optional Annotation Strip: If you need a name or date printed at the bottom of the photo, check Add Date / Name Strip. The crop region will automatically adjust to preserve the photo's aspect ratio without vertical distortion.
  7. Process & Download: Select Resize & compress. The output is checked for dimensions, format and file size before download. If the limit cannot be met at your chosen dimensions, increase the limit, reduce the dimensions or try another format. ApplyReady does not silently shrink your output. Use Replace or drop another file onto the workspace to start again.

2. Building an ATS-Friendly Resume

Applicant Tracking Systems (ATS) and recruiters prefer clean, single-column documents formatted with standard font hierarchies and true text streams. Here is how to use the builder:

  1. Start with Sample or Blank: Click Try a sample to see a complete professional example, or start fresh with empty fields.
  2. Fill in Contact Details: Enter your name, target title, email, phone, location, and professional links. Separator bullets will automatically appear only between populated fields.
  3. Add Experience, Education & Projects: Use the Add buttons to create dynamic entries. You can reorder entries with the Move Up and Move Down buttons or delete unnecessary sections.
  4. Customize Skills and Headings: Enter your skills in up to four labelled rows. Rename any row label or section heading (for example Internships instead of Work Experience); headings you leave unchanged follow the selected template's wording.
  5. Choose a design: Open Design to choose one of 15 ATS-friendly templates (filter by General, Students & freshers, Tech, Senior or Specialist roles), preview it, set A4 or US Letter paper, change typography and reorder sections. Your entered content is preserved when switching templates.
  6. Save Local Drafts & Backup: Open Draft & backup options below the content sections and turn on Save draft on this device on your own device. You can also use Save backup to download a JSON copy, then restore it with Import backup.
  7. Compare with a job description: In the download tab, paste the job advert to see which of its key terms your resume already uses and which are missing. The comparison runs on your device and the advert is not saved. Add only terms that truly describe your experience.
  8. Review & download: Open the download tab to check your details, then export PDF, editable Word or plain text. For characters outside the direct PDF engine's supported fonts, ApplyReady opens browser printing to preserve your text; choose Save as PDF. Review the downloaded file before submitting it.
