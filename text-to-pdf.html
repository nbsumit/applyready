    How it works

    The tool lays your text out on real pages with the measurements of the chosen font, wraps lines between words, and moves to a new page when one is full. The page count under the settings comes from the same layout, so the PDF has exactly that many pages. Line breaks and blank lines are kept as you typed them, runs of spaces are kept, and tabs become spaces up to the next tab stop. A word or link longer than a line is broken onto the next line rather than cut off. Invisible characters, such as zero-width spaces pasted from web pages, are removed.

    The PDF contains real, searchable text in Helvetica, Times or Courier. These are the standard PDF fonts: every PDF reader has them, so nothing is embedded and the file stays small, often only a few kilobytes per page. Before the file is offered, it is opened again and its pages are counted to make sure it is complete.

    Characters the PDF fonts cannot show

    The standard fonts cover English and Western European letters, accents such as é and ü, and common punctuation, including curly quotes, dashes and the euro sign. They have no shapes for Indian scripts such as Devanagari, for emoji, or for the rupee sign. Rather than print empty boxes, the tool lists every such character before export. It can replace the common ones with a faithful plain version (Rs. for the rupee sign, a hyphen for a minus sign, fi for the fi ligature that PDF copying produces). For text in Hindi or another script, use Print or save as PDF instead: it opens a clean print view of your text, and choosing Save as PDF in the print dialog makes a PDF with your device’s own fonts. Set the paper size in the print dialog.

    When to use something else

    This is for plain text such as a cover letter, a statement of purpose or notes. For a formatted resume, use the resume builder. For a document with tables or pictures, save it as PDF from Word, Google Docs or LibreOffice. To combine scanned pages, use image to PDF, and to see whether a finished file meets a form’s rules, use the file checker.

    Questions

    Can I write in Hindi or another Indian language?

    Not in the PDF this tool makes. It uses the standard PDF fonts, which every reader has but which only cover English and Western European letters. The tool lists any character it cannot show before you export. For Hindi, Tamil, Bengali and other scripts, use the print button it offers and choose Save as PDF in the print dialog: your browser then uses your device’s fonts.

    Why is the rupee sign not supported?

    The rupee sign was added to Unicode in 2010, after the standard PDF fonts were defined, so they have no shape for it. The tool offers to write Rs. instead, or you can use the print option, which uses your device’s fonts.

    Is the PDF searchable, and can I copy text from it?

    Yes. The PDF contains real text, not a picture of text, so PDF readers and portals can search it and you can copy text from it.

    How do I make the PDF fit a page limit?

    Watch the page count under the settings while you choose a smaller font size, single line spacing or narrow margins. The count is worked out with the same layout as the PDF, so the file has exactly that many pages.

    Does it keep my formatting from Word?

    No. It takes plain text: line breaks, blank lines, spaces and tabs are kept, but bold, colours, tables and pictures are not. For a formatted document, save it as PDF from Word, Google Docs or LibreOffice instead.

    Is my text saved or uploaded?

    No. The text stays in this page on your device and is never sent anywhere. ApplyReady does not save it, so closing or reloading the page clears it; download the PDF first.
