Batch image processor

Resize, compress or convert many photos and signatures with one set of settings, then download them one by one or together in a ZIP file. Your images stay on this device.

    Add the photos or signatures to process

    Drag them here, or

    JPG, PNG, WebP, GIF, BMP or AVIF, up to 50 MB each and 500 files at a time. You can paste images too. Processed on your device, never uploaded.

      How it works

      1. Add the images. Drag a whole folder's worth onto the box, choose them, or paste them. Each file is identified by its content, not its name: a file that is not an image, an empty file or an iPhone HEIC photo is listed with the reason and left out. You can add more images at any time.
      2. Choose the settings once. Pick a preset (passport photo, signature, profile photo, document scan) or set your own size, file limit and format. The same settings apply to every image in the list.
      3. Start. Images are processed a few at a time in the background, so the page stays usable while a large batch runs. Every row shows its status in words: waiting, processing, done, failed or cancelled. The bar at the top counts them and estimates the time left.
      4. Check and download. Each finished file is opened again and checked: the pixel size and the file size are read from the file itself, not taken from the settings. Download single files from their rows, or everything at once as a ZIP file.

      Resize options

      • Keep the original size only re-saves the image, for a new format or a smaller file.
      • Fit within a box keeps the proportions and makes the image no larger than the width and height you give. Small images are not enlarged.
      • Exact size, crop to fill gives exactly the width and height by trimming the edges evenly. Use it for photos that must be an exact size; check that no face is cut off at the top.
      • Exact size, add padding gives exactly the width and height without cutting anything off, and fills the space around the image with the background colour. It suits signatures, whose shapes vary.
      • Scale by a percentage makes every image the same fraction of its original size.

      When a file limit is set, the quality is lowered only as far as each image needs. If an image still does not fit at 50% quality and Allow smaller dimensions is on, its pixel size is reduced instead, and its row says so. For passport photos and signatures the exact pixel size matters, so those presets keep it fixed and report a failure instead.

      Limits, honestly

      • Up to 500 images at a time, each up to 50 MB and 50 megapixels. A large batch on a phone works, but takes longer; the page warns you when the files add up to more than 300 MB.
      • Nothing is saved. Results live in this tab until you download them, and the page asks before you leave with results you have not downloaded.
      • HEIC photos from iPhones cannot be opened by most browsers. The image converter page explains how to get a JPEG from your phone instead.
      • An animated GIF becomes a still image of its first frame.
      • Every image in a batch gets the same settings, and they all end up in one ZIP. When you prepare documents for several people one after another, as at a cyber cafe, applicant workspaces keep each person’s files, results and ZIP separate.
      • Saving a new copy drops the photo's hidden details, such as location (GPS), camera model and date taken. That is usually what you want for an application, but keep your originals if you need those details.

      To make files smaller without changing anything else, the image compressor opens with those settings ready. For a single photo where the crop matters, such as a face that must be centred, use the passport photo resizer or the signature resizer, which let you place the crop by hand. The guide to common photo upload errors explains what a portal's message usually means, and the tutorial on processing many photos at once shows presets, cancel, retry and the ZIP step by step.

      Questions

      How many images can I process at once?

      Up to 500 images in one batch, each up to 50 MB. They are processed a few at a time, so memory use stays limited even for a long list. If the files add up to more than about 300 MB, the page warns you that it may be slow on this device; you can still go ahead.

      Are my photos uploaded anywhere?

      No. The images are decoded, resized and compressed by your browser on this device. ApplyReady has no server that receives files, and the site’s Content Security Policy stops the page from sending data to any other address.

      What happens when I press Cancel?

      Images that are being processed stop straight away and are marked Cancelled, and so are the ones still waiting. Images that had already finished stay ready to download. Retry failed then processes the cancelled and failed images again with the current settings.

      Why did some images fail?

      Each failed row says why. The usual reasons are a damaged file, a photo above 50 megapixels, or a file limit that cannot be met at an exact pixel size. For the last one, raise the limit or turn on Allow smaller dimensions, then use Retry failed.

      Does it remove location and camera details?

      Yes. Every result is a new file written by the browser, and location (GPS), camera model, date taken and other hidden details are not copied into it. When a minimum size is set, only empty padding bytes are added to JPEG files.

      How are the finished files named?

      You can keep the original names, add a word to the end, or number the files in list order. If two results would have the same name, the second gets (2), the third (3), and so on. The names are the same in single downloads and in the ZIP file.

      Your images are processed in this browser and never leave your device. Nothing is saved after you close the tab.
