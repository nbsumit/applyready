About Sumit

Sumit Sengar is an independent software engineer based in India. He started ApplyReady in September 2026; the first version of the code was published on 30 September 2026, and every change since then is recorded in the project's public GitHub repository.

He is responsible for the code of every tool on the site and for what the guides and exam pages say. Questions and corrections reach him directly at hello@nbsumit.com.

Why he built ApplyReady

Indian exam and job portals each set their own rules for the photo, signature and documents a candidate uploads: an exact pixel size, a minimum and maximum file size in KB, and a file type. The rules differ from one exam to the next and change between notices. Candidates without photo-editing software may end up paying a cyber café to resize a single photo, or use free websites that upload their identity photos to a server, add watermarks or hide the real download behind advertising.

ApplyReady does the same work inside the browser. The photo, signature or resume never leaves the device, there is no account, and the tools state the exact pixel size and byte count of what they produce, so a candidate can check the file against the notice before uploading it.

How the pages are researched

  • Specifications come from the official notice. Every photo, signature and file-size figure on an exam page is taken from that exam body's own notice or information bulletin, and the row in the table links to it. Where a figure could not be confirmed in an official document, the page says so and links to the official site instead of giving a number.
  • Measurements come from the tools on this site. When a page says how large a file becomes at a given pixel size, the number was produced by running ApplyReady's own compressor on the test images published in /img/samples/, and the page names the input and output.
  • Changes are dated. Each guide shows when it was published and last updated, and each exam page shows the notice it was last checked against.

The full process, including how corrections are handled and how AI tools are used, is described in the editorial policy.
