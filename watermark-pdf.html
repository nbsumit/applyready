How it works

Type the text or pick a common one, then choose its size, angle, colour and strength. Centre puts one watermark in the middle of each page; Repeated across the page tiles it so it cannot be cropped away. The preview is the first page as it will come out. The watermark is drawn on top of the page, see-through, so the content underneath stays readable.

A watermark marks a copy; it is not a signature and does not protect the file from editing. Some forms ask for documents marked "self-attested" with your signature by hand; check what the form asks for. To number the pages as well, use Add page numbers, and to bring the marked file under an upload limit afterwards, use Compress PDF. To combine several marked documents, use Merge PDF.

Limits

Files up to 100 MB. The watermark uses the standard Helvetica font, which writes the letters A to Z (with accents such as é or ü), digits and common punctuation. Other scripts, such as Devanagari, and symbols such as ₹ cannot be written; the tool says which characters it cannot use instead of dropping them.

Your files are processed in this browser and never leave your device. Closing the tab clears them.

Common requests

Sending a copy of an ID to a recruiter

Choose For verification only, and Repeated across the page so the mark cannot be cropped away. Keep the strength low enough that the details stay readable in the preview.

"Self-attested copies"

A form that asks for self-attested copies usually wants your signature on each copy. The Self-attested mark can go on the page, but it does not replace the signature; sign the copies as the form asks.

The marked file is over the upload limit

Check the size shown with the result. If it is over the limit, bring it down with Compress PDF, then open it once to check that the mark is still readable.

Questions

Which text should I use for document copies?

Use what the form or the person asking for the document says. "Copy" and "For verification only" are common for copies of ID and certificates sent with an application.

Can I write the watermark in Hindi or another script?

Not with this tool. It uses the standard PDF font, which writes Latin letters (A to Z with accents), digits and common punctuation. It tells you which characters it cannot write rather than leaving gaps.

Will the watermark make the page hard to read?

It is see-through. Strength sets how visible it is: 20 to 30 percent keeps text easy to read, and the preview shows the result.

Can someone remove the watermark?

Someone with PDF editing software can, as with any watermark. It marks a copy clearly; it does not lock the file.

Is a watermark the same as self-attestation?

No. Self-attestation usually means signing a copy yourself. A typed "Self-attested" mark does not replace your signature if the form asks for one.

Is my PDF uploaded?

No. The watermark is added by your browser on this device.
