Your data

ApplyReady has no accounts and no server that keeps your data. Everything it remembers is stored by this browser on this device. This page lists all of it, with a way to back it up and to delete it.

      How browser storage works, honestly

      ApplyReady runs entirely in your browser, so the browser is also where it keeps things. That has real limits:

      • Clearing site data removes it. Clearing browsing data, cookies and site data, or this site’s storage, deletes saved resumes and settings. Some cleaning apps do this too.
      • Private windows forget. In a private or incognito window, everything is deleted when the window closes.
      • Browsers can evict data. When a device runs low on space, a browser may delete data from sites you have not used recently, unless the storage is marked persistent.
      • Each browser is separate. Resumes saved in Chrome are not visible in Firefox, and nothing moves between your phone and your computer by itself.

      A backup file is therefore the safe copy of your resumes. Keep it somewhere you control, and import it on any device. On a shared or cyber cafe computer, delete everything here when you finish, and also delete the files you downloaded from the Downloads folder. For more on using shared computers safely, see staying safe with document uploads, and the privacy policy for the full picture.

      Tools that work on files, such as the file checker and the PDF and image tools, keep files in the page’s memory only. Nothing about those files is stored, and closing the tab forgets them.

      Questions

      Does ApplyReady keep a copy of my resumes on a server?

      No. ApplyReady has no accounts and no server that stores anything you make. Saved resumes are kept by your browser on this device only, which is why they do not appear on your other devices and why a backup file is the safe copy.

      Why did my saved resumes disappear?

      The usual reasons are clearing browsing data or site data, using a private or incognito window (its storage is deleted when the window closes), using a different browser or device, or the browser removing site data when the device ran low on space. Import your latest backup file to bring them back.

      How do I move my resumes to another phone or computer?

      Select Download a backup of all resumes on this page, move the file to the other device (by email to yourself, a USB drive or cloud storage), open this page there and select Import a backup. Each resume is added as a new copy; nothing on the other device is overwritten.

      What does Keep my data do?

      It asks the browser to mark ApplyReady’s storage as persistent, so the browser does not delete it on its own when space runs low. The browser decides: some agree straight away, some only for sites you use often or have bookmarked or installed, and some ask you. It never protects data from you clearing site data yourself.

      Does deleting here remove files I downloaded?

      No. PDFs, images, Word files and backups you downloaded are in your Downloads folder, outside the browser’s site storage. Delete them there if you no longer need them, especially on a shared computer.
