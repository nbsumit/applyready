How it works, and how to read the result

A form usually states three things: a pixel size, a file-size range in KB and a file type. The resizer asks which requirement you are meeting, crops to that shape, then compresses until the file fits. It always starts at high quality and only lowers it as far as the limit needs.

After processing, the result shows the requirement and your file side by side. File size gives the size in KB and the exact byte count, because portals count bytes and 1 KB is 1,024 bytes. Dimensions are read back from the finished file, not from the settings, so the number is what the portal will see. Download when every row has a tick; if one does not, change the setting it names and run it again.

Need the same size for a whole folder of photos? Use the batch image processor. For the two most common jobs, the passport photo resizer and the signature resizer open with their sizes already chosen, and every other image tool is listed under image tools. To clean up a signature photographed on paper first, use the signature cleaner. If a portal still refuses the file, match its error message to the fix, and to keep a photo sharp under a tight limit read how to shrink a photo without blur.

Questions

How do I resize a photo to the exact size a form asks for?

Choose the requirement that matches the form, or Custom size to type the width, height and file limit yourself. Add the photo, drag it into position inside the frame, then select Resize and compress. The result shows the finished file next to the requirement, read back from the file itself, so you can see it fits before you download.

Is my photo uploaded anywhere?

No. The image is decoded, cropped and compressed by your browser on this device. ApplyReady has no server that receives files, and the site’s Content Security Policy stops the page from sending data to any other address.

The form gives the size in centimetres. What do I enter?

Open Size, file limit and format, set the unit to centimetres and the print DPI the form mentions (300 if it says nothing). The resizer converts the centimetres to pixels for you. The guide on pixels, centimetres and DPI explains the arithmetic.

Why does my file need a minimum size in KB?

Some portals reject files below a minimum, often to catch blank or broken uploads. Enter the minimum in the Minimum (KB) field. For JPEG files the resizer adds harmless padding inside the file when a small image would otherwise fall below it; the picture itself is not changed.

Which format should I choose?

JPEG for photos and for any portal that does not say otherwise: it is accepted almost everywhere and makes the smallest files. PNG keeps sharp edges and transparency but is much larger, so it rarely fits a small KB limit. WebP is small and sharp, but many application portals still refuse it.

Can I resize many photos at once?

This page prepares one image at a time with a precise crop. To apply the same size to a whole folder of photos, use the batch image processor, which resizes, compresses or converts many files and gives you one ZIP file.
