Official Exam Guidelines Reference

UPSC Civil Services / NDA / CDS:

Photo must not be more than 10 days old with candidate's name and date printed clearly at the bottom. Max 50KB, min 20KB.

SSC CGL / CHSL / MTS:

Signature must be on white paper in black/blue ink, 140x60px, strictly between 10KB to 20KB. Illegible signatures lead to rejection.

IBPS Bank PO / Clerk / SBI:

Photograph dimensions 200 x 230 pixels, file size 20KB - 50KB. Signature dimensions 140 x 60 pixels, file size 10KB - 20KB.
