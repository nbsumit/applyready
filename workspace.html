Applicant workspaces

Prepare documents for one person after another at a cyber cafe, computer centre or placement office. Each applicant gets a separate space for their photo, signature and scans, with one ZIP to download, and finishing an applicant wipes everything of theirs from this tab.

Temporary workspace: nothing is saved. Closing or reloading this tab erases every applicant’s files.

          How it works

          1. Set up the session once. Open Session settings to match the forms you fill most: the passport photo’s width, height and size limit, the same for the signature, a size for compressed images, the PDF limit and how ZIP files are named. Every applicant in the session uses them.
          2. Add an applicant. Type their name if you like, or keep “Applicant 1”. Add their photo, signature and scans by choosing, dragging or pasting them. Each file is identified by its content, so a file that is not an image or a PDF is refused with the reason.
          3. Make each file with one click. On a picture choose Passport photo, Signature, Compress to KB or Convert to JPEG. On a PDF choose Compress PDF to limit. Select several files to combine pictures into one PDF, or to merge PDFs. Tasks run in the background, so you can keep working or switch applicants.
          4. Check and download. Every result is opened again and measured before it is listed: pixels, kilobytes and pages come from the finished file, not from the settings. Download files one by one, or everything for that applicant as one ZIP.
          5. Finish the applicant. Finish applicant removes their files, results and name from the tab. If something was not downloaded yet, you are asked first. Then the next applicant’s space is shown, or you add a new one.

          Why a separate space for each person

          At a shared computer the biggest risk is a mix-up: the last customer’s photo uploaded with this customer’s form, or a stranger’s certificate left on screen. Here each applicant is a separate object in the page’s memory with its own files, results and download links. Switching applicants rebuilds the screen from that applicant alone, a result always goes back to the applicant whose task made it, and finishing an applicant cancels their tasks and releases their files at once. Nothing about applicants is written to the browser’s storage. Our guide to staying safe with document uploads has more on shared computers.

          Limits, honestly

          • Everything lives in this tab. Closing or reloading it, or the browser running out of memory, loses every applicant’s files. The page warns before closing while files are present.
          • Files you download are ordinary files in the computer’s Downloads folder. This page cannot delete them; remove them after uploading, and clear the browser’s download list on a shared computer.
          • The passport photo is cropped from the centre. For a face that is not centred, the passport photo resizer lets you place the crop by hand. The signature cleaner whitens the paper of a phone photo of a signature before you add it.
          • Compressing a PDF redraws its pages as pictures, so text can no longer be selected. Combining pictures into one PDF puts each on an A4 page, in the order of the list. Merging PDFs keeps their pages as they are, so a merged file can be over the limit; it then offers to compress it.
          • Up to 50 files per applicant, 50 MB per image (50 megapixels at most) and 100 MB per PDF. HEIC photos from iPhones cannot be opened by most browsers.
          • For one large batch of photos with the same settings, such as a class’s ID photos, the batch image processor is quicker.

          Questions

          Is anything saved after an applicant is finished?

          No. Finishing an applicant stops their running tasks, releases the temporary links the browser made for their files and results, and removes every reference to them from the page. Nothing about applicants is ever written to the browser’s storage, so there is nothing left to clear afterwards. The only thing the site remembers is that this tool was used recently, which you can switch off on the Your data page.

          What happens if I close or reload the tab by mistake?

          Every applicant’s files and results are lost, because they only exist in this tab. The browser asks you to confirm before it closes or reloads the tab while any applicant still has files. Download each applicant’s ZIP before you finish them.

          Can one applicant’s files end up in another applicant’s download?

          Not through this tool. Each applicant is kept separately: their own files, results and download links. A task started for one applicant delivers its result only to that applicant, even if you switch to someone else while it runs, and finishing an applicant cancels their tasks. The ZIP for an applicant contains only that applicant’s results.

          How is the photo cropped?

          The passport photo action crops from the centre to the exact width and height in the session settings, then lowers the JPEG quality only as far as needed to meet the size limit. If the face is not in the middle of the picture, use the passport photo resizer instead, where you can place the crop by hand, and add the result to the applicant afterwards.

          Why did a compressed PDF lose its selectable text?

          Compressing a PDF to a limit redraws every page as a picture, so text can no longer be selected, but numbers and stamps stay readable. If a PDF is already under the limit it is kept exactly as it is. If it cannot get under the limit, the smallest readable version is offered with a warning so you can decide.

          Does it work on a phone or an older computer?

          Yes, in a recent version of Chrome, Edge, Firefox or Safari. Photos are processed in the background a few at a time, so the page stays usable. A phone has less memory, so very large scans take longer; the limits are 50 files per applicant, 50 MB per image and 100 MB per PDF.
