      How it works

      Add a PDF and choose how to split it. Extract pages puts the pages you choose into one new file, in the order you type them, so "5, 1-3" gives page 5 first. One PDF per range makes a file for each range. Every page makes one file per page, and Equal parts makes a new file every few pages. Select page thumbnails to fill in the page list, or type it; a mistake such as a page number past the end is explained under the field.

      Pages are copied, not redrawn, so text stays sharp and selectable and each page keeps its size and rotation. Every file is opened again and its page count checked before it is offered. To put pages from different files together, use Merge PDF; to reorder, turn or delete pages in one file, use Organise PDF pages; and to save pages as pictures instead, use PDF to images.

      Limits

      Files up to 100 MB, and up to 500 output files in one go. Fonts and images shared by many pages are copied into each new file, so the parts together can be larger than the original. Bookmarks and form fields are not kept in the new files.

      Your files are processed in this browser and never leave your device. Closing the tab clears them.

      Questions

      How do I take just a few pages out of a PDF?

      Choose Extract pages, then select the pages or type them, for example 2-4, 7. Select Split PDF and download the new file. The original file is not changed.

      What does "7-" mean in the page list?

      From page 7 to the last page. You can also write a range such as 3-5, a single page such as 9, or several separated by commas.

      Can I get every page as a separate PDF?

      Yes. Choose Every page. You can download each file on its own or all of them in one ZIP file, named with the page number so they sort in order.

      Will the split pages look the same?

      Yes. Pages are copied as they are, so text, images, size and rotation stay the same. Nothing is compressed or redrawn.

      Why are the parts bigger than the original in total?

      A font or logo used on every page is stored once in the original, but each new file needs its own copy. Each part is complete on its own, which is what makes it bigger in total.

      Is my PDF uploaded?

      No. It is read and split by your browser on this device, and closing the tab clears it.
