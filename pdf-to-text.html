How it works

A PDF made from a word processor stores its text, and that text is read page by page as soon as you add the file. Lines are rebuilt from the position of each word on the page, so headings, lines and paragraphs come out separately; columns and tables are read from left to right and may need tidying. With Mark where each page starts on, each page begins with a line such as "Page 2".

A scanned document is different: each page is a picture of text, so there are no words to copy. ApplyReady does not read pictures of text (this is called OCR), and it tells you which pages had no text instead of guessing. To keep a scanned page as an image, use PDF to images; to make it smaller for a portal, use Compress PDF. If you are copying details into a resume, the resume builder takes plain text well.

Limits

Files up to 100 MB. Text written in a font without a proper character map can come out as wrong characters; that is a fault in how the PDF was made, and the only cure is the original document.

Your files are processed in this browser and never leave your device. Closing the tab clears them.

Questions

Why is no text found in my PDF?

The pages are probably scans or photos, which are pictures of text rather than text. ApplyReady does not do OCR (reading text from pictures), so it lists those pages instead. Ask for the original document, or type the text yourself.

Does it keep the layout?

It keeps lines and paragraphs, and leaves a blank line between blocks. Columns and tables come out as plain lines read from left to right, so check them before you paste.

Can I read only some pages?

Yes. Type the pages, for example 2-3, then select Extract text again.

Some characters come out wrong. Why?

The PDF uses a font that does not say which letter each shape stands for. The text looks right on screen but cannot be read back reliably from that file.

How do I save the text?

Copy text puts it on your clipboard. Download .txt saves a plain text file that opens in any text editor.

Is my PDF uploaded?

No. The text is read by your browser on this device.
